# hello-world
Repository for final project in Programming and Statistics
I'm working with Aishwarya and Nicole.
Dataset info: Our dataset is called breastcancerbycountry.csv and it gives breast cancer data for patients in different countries. It contains annual statistics from 2000 to 2026 for 50 countries capturing longitudinal demographic, epidemiological, screening, and treatment access variables. It was collected for researchers and individuals who want to analyze the global trends in breast cancer statistics. 
Limitations: The dataset does not show how the Treatment_Access_Score was calculated. Also, there is not data for every country in the world.
